## Review Focus

1. **PR vindo de fork / sem secrets** → o workflow não usa nenhum secret, então roda igual. *Teste: Task 2, Step 2 (grep por `secrets.`).*
2. **Lockfile desatualizado** → `npm ci` falha em vez de instalar versões diferentes. *Teste: Task 2, Step 3 (`npm ci` local passa).*
3. **Push novo no mesmo PR** → o run anterior é cancelado (`concurrency` com `cancel-in-progress: true` por ref). *Teste: Task 2, Step 2.*
4. **Erro de tipo em qualquer arquivo** → o job falha no passo de `tsc`, não só no build. *Teste: Task 2, Step 3.*
5. **Primeiro run real no GitHub** → verde. *Teste: Task 2, Step 5.*
